## 二、与 `08` 文档 RL 首战最相关的既有工作

### 2.1 去耦电容 + RL 学术脉络（KAIST 为主线）

这些工作解决的是：**在 PDN 的 N 个已知候选端口里，选哪些打电容、打什么容值**，输入通常是预先算好的多端口阻抗矩阵 Z，目标是频域自阻抗/转移阻抗低于 target impedance。

| 工作 | 链接 | 核实 | 对你的价值 |
|---|---|---|---|
| Deep RL Framework for Optimal Decap Placement on General PDN（EPEPS 2021） | [IEEE 9609194](https://ieeexplore.ieee.org/document/9609194) | ⚠️ 需 IEEE 权限 | 指针网络 + REINFORCE；与 `08` §4.2「候选生成 + 排序」同构 |
| Transformer RL for PDN Optimization of HBM（TMTT 2022） | [arXiv:2203.15722](https://arxiv.org/abs/2203.15722) ✅ | ✅ 可访问 | Attention 参数化策略；context embedding 做跨实例泛化；打赢 GA/随机搜索/早期 RL |
| RL for Decap Optimization in Post-Layout PDN（2025） | [IEEE 11511858](https://ieeexplore.ieee.org/document/11511858) | ⚠️ 需 IEEE 权限 | post-layout 场景，最接近「布局后优化」 |
| Hierarchical Decap Optimization for 2.5D IC PDN | [arXiv:2407.04737](https://arxiv.org/abs/2407.04737) | ⚠️ 未逐条读全文 | 频域+时域双目标；⚠️ Opus5 提醒作者曾挂 comment 说数据待重验 |
| **PhysEDA**（2026-05） | [arXiv:2605.10547](https://arxiv.org/abs/2605.10547) ✅ | ✅ 可访问 | 曼哈顿距离衰减物理先验 + **Potential-Based Reward Shaping（PBRS）**；DPP 稀疏奖励场景 +10.8% |

**关键差异（Opus5 强调，我同意）**：

```
学术 decap RL：  已知候选端口 + Z 矩阵 → 选电容组合（组合优化）
你要做的：      2D 几何摆放 + 封装/重叠/禁布/走线通道 + 电气目标（几何+电气复合）
```

**能直接搬的**：
- MDP 结构：候选集选择，而非连续坐标
- 策略网络：指针网络 / Attention 打分头
- 训练路径：REINFORCE → PPO；随机数据预训练 → 零样本泛化
- 奖励塑造：PhysEDA 的 PBRS（有策略不变性理论保证）

**不能搬的**：
- 他们的奖励 = Z 矩阵求解，不是你的解析环路电感公式
- 他们的环境没有几何约束（封装尺寸、Keepout、限高、重叠）

**结论**：你的 `08` §4.2「候选生成器 + 从 N 个候选里选 1 个」在 decap RL 脉络上已被反复验证；**GNN 分支是你相对学术工作的增量**（他们多数没有图结构泛化）。

### 2.2 可直接参考的物理评估器：PAGA

| 项 | 内容 |
|---|---|
| 项目 | [SoFoolish250/Physics-Assisted-Genetic-Algorithm-PAGA-for-Decap-Optimization](https://github.com/SoFoolish250/Physics-Assisted-Genetic-Algorithm-PAGA-for-Decap-Optimization) ✅ |
| 核实 | 存在，11 stars；浙大 Li Jiang / Ling Zhang 组 |
| 许可 | **GPL-3.0（传染性）** ⚠️ |
| 能力 | 输入 `.SNP` / `.npy` 的 Z 参数矩阵；用 `scikit-rf` 做网络参数运算 + 解析电容模型算阻抗曲线；**不含 EM 求解器** |
| 对你的价值 | 解决 `08` §4.5「评估器校准」的鸡蛋问题 |

**Opus5 建议的三层校准链（我认为对 M2/M3 进度最有价值）**：

```
第 1 层（快，训练用）：  解析环路电感公式（你 08 §1.3 已有）
第 2 层（中，验证用）：  Z 矩阵 + scikit-rf 评估器（参考 PAGA 思路自建，不直接 copy GPL 代码）
第 3 层（慢，终验）：    SI 真实 PDN 仿真（20 例抽样）
```

这样 RL 开发不必等 SI 仿真排期才能开工；SI 侧只需一次性提供几个典型叠层的 `.SNP` 文件（低成本）。

相关论文：[Decoupling Optimization for Complex PDN Using Deep RL（NSF 公开 PDF）](https://par.nsf.gov/servlets/purl/10465812) — 讲如何快速生成 Z 矩阵，可与 PAGA 路线配合阅读。

> ⚠️ **GPL-3.0 注意**：可以**读方法、自建实现**；不要把 GPL 代码直接合进内网产品，使用前确认许可证合规。

### 2.3 板级（PCB，非芯片）RL 布局：三个值得看的项目

#### A. RL_PCB（目前唯一能跑的开源板级 RL 布局）

| 项 | 内容 |
|---|---|
| 链接 | [LukeVassallo/RL_PCB](https://github.com/LukeVassallo/RL_PCB) ✅ |
| 核实 | MIT 许可，65 stars；DATE 2024 相关工作 |

| 对你的价值 | 独立验证了与你相同的核心判断：主器件为中心 + 搜索空间离散化 + 领域先验塑造奖励；**没有 GNN、没有开源代码** — 你的 GNN 分支若做出来是明确增量 |
| 关键细节 | 用 Top-K 松弛 net proximity 硬约束；奖励 = α·非重叠 + (1-α)·网络邻近 |
