封装形状还原 — 设计部需提供字段清单

一个器件对应一个 .json；顶层为项目/器件元数据 + units + pins[]。

================================================================================
文件约定
================================================================================
格式 JSON（UTF-8）；建议文件名含位号，如 U1_LT86121_QFN88.json
一个 JSON = 一个器件（refdes 为单个字符串，如 "U1"）
顶层必填：project_code、refdes、units、pins[]
填写参考见：封装形状还原-设计部填写参考.json、封装形状还原-示例.json

================================================================================
顶层字段 — 入库与检索（与 units 同级）
================================================================================
字段              必填    类型          说明
----------------  ------  ------------  ------------------------------------------
project_code      是      字符串        项目/板子编码；可为 "1188009" 或 "1188009画板子"
project_name      否      字符串        板子名称
units             是      字符串        长度单位，如 "mils"、"mm"
layers            否      整数          板子层数
devicetype        否      字符串        器件类型/型号
packagesymbol     否      字符串        封装符号
value             否      字符串        器件值/规格
refdes            是      字符串        位号，单个，如 "U1"
X                 否      数值/字符串   位号在板上的 X 坐标（与 pins[].x 不同，仅 JSON 归档不入库；也兼容小写 x）
Y                 否      数值/字符串   位号在板上的 Y 坐标（与 pins[].y 不同，仅 JSON 归档不入库；也兼容小写 y）
top_side          否      布尔/0|1      1/true=正面，0/false=反面，默认 1

唯一键：project_code + refdes（MySQL UPSERT）

================================================================================
坐标说明
================================================================================
三类坐标，不要混用：

1）顶层 X, Y — 位号/器件在板上的位置，单位与 units 一致，仅 JSON 归档（兼容小写 x, y）
2）pins[].x, y, rotation — Pin 在封装上的位置，封装坐标系（数值可为字符串）
3）shapes 里的图元坐标 — 焊盘栈局部坐标，原点在引脚连接点 (0,0)

================================================================================
pins[] 每个 Pin 对象
================================================================================
字段            必填    类型          说明
--------------  ------  ------------  ------------------------------------------
pin_number      否*     整数/字符串   引脚号；为空时用 padstack 作为 pin 标识
padstack        是      字符串        焊盘栈名
x               是      数值/字符串   Pin 连接点 X（封装坐标）
y               是      数值/字符串   Pin 连接点 Y（封装坐标）
rotation        是      数值/字符串   Pin 旋转角（度）
figure_type     是*     字符串        Allegro Figure 原名
width           条件    数值/字符串   焊盘宽度或外径
height          条件    数值/字符串   焊盘高度
corner_radius   可选    数值/字符串   圆角半径
chamfer_ratio   可选    数值/字符串   倒角比例 0~1
inner_diameter  可选    数值/字符串   内径（DONUT）
sides           可选    整数          边数
shape_name      可选    字符串        Shape/Flash 符号名
offset_x        可选    数值/字符串   Padstack pad 偏移 X
offset_y        可选    数值/字符串   Padstack pad 偏移 Y
shapes          可选    数组          异形轮廓（必须为数组），仅 SHAPE/FLASH

* pin_number 与 padstack 至少 padstack 必填；pin_number 空则取 padstack
* 做形状还原时 figure_type 必填

================================================================================
shapes 数组结构（必须为数组；void 可省略，默认 []）
================================================================================
"shapes": [
  {
    "shape": [ {"type":"segment", ...} ],
    "void": [ {"type":"polygon", "points":"..."} ]
  }
]

· shapes 必须是数组 []，不能写成单个对象 {}
· shape、void 均为**单层图元数组**（与 segment/arc/polygon 同级），不要用 [[...]] 双层包裹
· void 可省略，无孔时写 [] 或不写 void 字段
· 多个孔：void 里写多个 polygon 图元，或 shapes[] 拆成多个 {shape, void} 岛

================================================================================
/similar 接口返回（results[] 每项）
================================================================================
project_code   项目编码
refdes         位号
minx / miny / maxx / maxy   候选封装铜箔包围盒（与 units 同单位）

================================================================================
入库方式
================================================================================
专用入库：POST /api/v1/footprints/library
相似检索：POST /api/v1/footprints/similar（仅检索，不入库）
