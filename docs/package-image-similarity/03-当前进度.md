---

## 1. 一句话状态

JSON → fpgeom → **MySQL** `footprint_library`（唯一键 `project_code + refdes`）；检索时 pin 硬过滤 + Shapely IoU 精排；**`/library` 入库、`/similar` 仅检索**。

---

## 2. 已完成

| 事项 | 产出 |
|---|---|
| JSON 还原 + fpgeom | `footprint_json.py` / `fpgeom.py` |
| MySQL 表 + 读写 | `schema.sql` / `footprint_db.py`（pymysql） |
| HTTP API | `api_app.py` — `/library`、`/similar`、`/settings`、`/health` |
| CLI 检索 | `query_similar.py` |
| 设计部 JSON 规范 | 顶层 project_code/refdes/units/pins[] 等 |

---

## 3. 技术结论

| 项 | 结论 |
|---|---|
| 数据库 | **MySQL 8+**（PoC 选型，非 PostgreSQL） |
| 唯一键 | project_code + refdes |
| 主相似度 | Shapely 几何 IoU（IoU 不入库） |
| 硬过滤 | pin_count 相等 |
| /similar 返回 | project_code、refdes、minx/miny/maxx/maxy |
| 入库入口 | **仅** POST `/library` |

---

## 4. 部署步骤

```bash
pip install -r requirements.txt
cp config/footprint_sim.example.yaml config/footprint_sim.yaml
python setup_db.py
python run_api.py
```
