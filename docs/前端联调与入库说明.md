# 前端联调与入库说明

## 架构

| 组件 | 路径 | 端口 |
|------|------|------|
| 入库 API | `ingest_service` → `run_ingest_app.py` | 8000（入库机） |
| 检索 API | `search_service` → `run_search_app.py` | 8000（检索机） |
| 前端 | **`DAY002/desktop` 单独交给前端** | 5173（开发） |
| 数据库 | MySQL `footprint_sim` | `schema.sql` |

前端只对接 **search_service**；二开/OA 只对接 **ingest_service**。两台机器可都用 8000。

## 1. 初始化数据库

```powershell
pip install -r requirements.txt
python setup_db.py
```

## 2. 启动检索后端（前端联调）

```powershell
cd search_service
python run_search_app.py
```

健康检查：`GET /api/health` → `{"ok":true,"service":"search"}`

## 3. 启动入库后端（二开/OA）

```powershell
cd ingest_service
python run_ingest_app.py
```

## 4. 启动前端

```powershell
cd DAY002\desktop
npm install
npm run dev
```

浏览器 http://127.0.0.1:5173 ，Vite 将 `/api` 代理到检索机 8000。

环境变量：`VITE_API_BASE=http://检索机IP:8000`

## 5. 页面与 API 对应

| 页面 | 使用的 API |
|------|------------|
| 对话检索 | `POST /api/agent/sessions`、`POST /api/agent/chat` |
| 推荐结果 | 会话内结果 / sessionStorage |
| PDF 文档 | `GET /api/pdf`、`GET /api/pdf/search`、PDF 详情与 region |

已移除：独立形态 HTTP（原 `api_app.py`）、一体版 `run_agent_app.py`、测评/Eval、Footprint 调试页。

## 6. Electron（可选）

`PCB_AGENT_API` 指向 search_service 地址；EDA `--jsonDir=` 仍 POST `/api/agent/sessions`。
