# PCB 设计业务基础与术语表

> 面向项目组非硬件背景成员（算法 / 后端 / 产品）的入门材料。
> 目标：读完之后能听懂 PCB 工程师说话，能判断一条"设计规范"属于哪一类、能不能被程序执行。

---

## 一、PCB 设计的完整流程

理解流程是理解需求的前提。一块板子从想法到量产，大致经过下面这些阶段：

| 阶段 | 中文 | 英文 | 产出物 | 我们的 AI 介入点 |
|---|---|---|---|---|
| 1 | 需求与方案 | Requirement / Architecture | 框图、器件选型表 | 规范问答（选型规范） |
| 2 | 原理图设计 | Schematic Capture | 原理图、BOM | 规范问答、原理图规则检查 |
| 3 | 网表生成 | Netlist Generation | Netlist（网络连接表） | 数据源 |
| 4 | 封装与库 | Footprint / Library | 焊盘、封装 | 库规范检查 |
| 5 | 叠层设计 | Stackup Design | 层叠表、阻抗表 | 规范问答 |
| 6 | **布局** | **Placement** | 器件坐标 | **辅助布局（本项目重点）** |
| 7 | 布线 | Routing | 走线、过孔 | 远期 |
| 8 | 检查 | DRC / DFM / DFA | 检查报告 | 规则引擎 |
| 9 | 生产输出 | Fabrication Output | Gerber / ODB++ / IPC-2581 | 数据源 |

**关键认知**：布局（Placement）决定了后面 70% 以上的成败。布局做坏了，布线再牛也救不回来，信号完整性、散热、EMC 全部受影响。这也是为什么"辅助布局"值得投入大工程。

## 二、必须掌握的核心术语

### 2.1 结构与几何类

- **Net（网络）**：一组电气上连在一起的引脚。原理图上一根线，实际连接了 N 个引脚。这是图建模里最重要的对象——它天然是一条**超边（hyperedge）**，连接 2 个到上千个节点。
- **Netlist（网表）**：所有 Net 的清单，形如 `NET_VCC3V3: U1.12, C5.1, C6.1, R3.2 ...`。这是原理图到 PCB 的桥梁，也是我们构图的主数据。
- **Footprint（封装）/ Symbol**：器件在板上占的物理形状，包含焊盘位置、丝印、禁布区。Allegro 里是 `.dra` / `.psm` 文件。
- **Padstack（焊盘叠）**：一个焊盘在各层的形状定义（表层、内层、阻焊层、钻孔）。
- **Via（过孔）**：层间连接。细分为 Through Via（通孔）、Blind Via（盲孔）、Buried Via（埋孔）、Micro Via（微孔，HDI 用）。
- **Layer / Stackup（层 / 叠层）**：板子是多层三明治结构，如 8 层板 = 4 层信号 + 2 层电源 + 2 层地。叠层直接决定阻抗。
- **Plane（平面层）**：整层大铜皮，通常是 GND 或 Power。
- **Board Outline（板框）**：板子外形，由结构工程师给（通常来自 DXF / STEP）。
- **Keepout / Keepin（禁布区 / 限布区）**：不能放器件或走线的区域，比如螺丝孔周围、天线净空区。
- **Height Restriction（限高区）**：受外壳限制，某区域器件不能超过一定高度。
- **Room / Region**：Allegro 中的逻辑分区，把某个功能模块的器件圈在一起。**这是我们做"分区推荐"最自然的落点。**
- **Fiducial（基准点）**：贴片机光学定位用的圆形标记，位置有严格规范。
- **Panelization（拼板）**：多块小板拼成一大块过产线。

### 2.2 约束与规则类（这一类最容易被程序化）

- **Constraint（约束）**：Allegro 里所有可执行规则的统称，在 **Constraint Manager（CM，约束管理器）** 里维护。
- **PCS / SCS / ECS**：Physical / Spacing / Electrical Constraint Set，即物理约束集（线宽、过孔类型）、间距约束集（线到线、线到焊盘的最小间距）、电气约束集（等长、拓扑、串扰）。
- **Design Rule Check（DRC）**：规则检查，Allegro 会实时打红点。**注意：DRC 只覆盖能被 CM 表达的规则，设计规范里大量"软规则"是 DRC 查不出来的——这正是我们规则引擎的价值空间。**
- **Differential Pair（差分对）**：一对等长等距、反相传输的线，如 USB、PCIe、以太网。约束项包括对内偏差（Intra-pair Skew）、对间间距。
- **Length Matching / Delay Tune（等长 / 绕线延时调节）**：让一组信号的传输延时一致，典型如 DDR 的数据组。
- **Impedance Control（阻抗控制）**：单端常见 50Ω，差分常见 90Ω（USB）/ 100Ω（以太网、PCIe）。由线宽、介质厚度、介电常数（Dk / Er）共同决定。
- **Back Drilling（背钻）**：把过孔多余的"残桩（Stub）"钻掉，高速信号必备。

### 2.3 信号与电源完整性（SI / PI / EMC）

- **Signal Integrity（SI，信号完整性）**：信号在传输过程中是否失真。关键词：反射（Reflection）、串扰（Crosstalk）、码间干扰（ISI）、眼图（Eye Diagram）。
- **Power Integrity（PI，电源完整性）**：电源网络能否稳定供电。关键指标是 **PDN 阻抗（Power Distribution Network Impedance）** 要低于 **Target Impedance（目标阻抗）**。
- **Return Path（回流路径）**：高频电流总是沿着阻抗最小路径回流，即紧贴信号线正下方的参考平面。**参考平面被割裂 → 回流路径断裂 → EMI 爆炸。**这是 90% 的 EMC 问题根源。
- **Reference Plane（参考平面）**：信号线正下方/上方的完整铜平面。
- **Decoupling Capacitor（去耦电容 / 退耦电容）**：给芯片就近提供瞬态电流。规范里典型表述是"0.1uF 电容必须放在 BGA 电源引脚 5mm 以内，且过孔尽量靠近焊盘"。**这类规范是可量化、可自动检查、也可作为布局奖励项的典范。**
- **EMC / EMI（电磁兼容 / 电磁干扰）**：板子对外辐射不能超标，对外界干扰要能扛住。
- **3W 规则**：线间距 ≥ 3 倍线宽，降低串扰。
- **20H 规则**：电源平面比地平面内缩 20 倍层间距，抑制边缘辐射。
- **Crosstalk（串扰）**：相邻走线互相干扰，分近端（NEXT）和远端（FEXT）。

### 2.4 热与结构

- **Thermal Via（散热过孔）**：把热从器件底部导到内层/背面铜皮。
- **Junction Temperature（结温）**：芯片内部温度，是可靠性红线。
- **Copper Pour / Flood（铺铜）**：大面积覆铜，用于散热和降低阻抗。
- **IDF / IDX / STEP**：机械（MCAD）与电气（ECAD）协同的数据格式，用来同步板框、限高、连接器位置。

### 2.5 可制造性（DFx）

- **DFM（Design for Manufacturing，可制造性设计）**：板厂能不能做出来。如最小线宽/线距、最小孔径、孔到铜距离。
- **DFA（Design for Assembly，可装配性设计）**：贴片厂能不能贴。如器件间最小间距、极性方向一致性、大小器件的"阴影效应"。
- **DFT（Design for Test，可测试性设计）**：能不能测。如测试点（Test Point）数量、直径、间距。
- **ICT / FCT**：在线测试 / 功能测试。

### 2.6 数据格式

| 格式 | 用途 | 是否结构化 | 对我们的价值 |
|---|---|---|---|
| `.brd` | Allegro 板文件（私有二进制） | 需工具解析 | **核心数据源** |
| `.dsn` | OrCAD Capture 原理图 | 私有 | 网表来源 |
| Allegro **extracta** 导出 | 文本表格（器件、引脚、网络、坐标） | ✅ 高度结构化 | **首选提取方式** |
| **SKILL** 脚本 | Allegro 内置 Lisp 方言，可读写板数据 | ✅ | **插件与自动化的核心** |
| **IPC-2581** | 开放的 PCB 数据交换标准（XML） | ✅ | 中立、跨 EDA、易解析 |
| ODB++ | Valor 制造数据格式 | ✅ | 制造侧数据 |
| Gerber X2 | 光绘文件 | 部分 | 兜底 |
| **Constraint Manager 导出** | 约束表（可导 CSV / XML） | ✅ | 规则库对齐的黄金数据 |

## 三、"布局"到底在做什么（算法侧重点看）

给定：板框、叠层、网表、器件封装尺寸、结构约束（连接器/接口位置固定）、电气约束、热约束。
求解：每个器件的 `(x, y, rotation ∈ {0°,90°,180°,270°}, side ∈ {Top, Bottom})`。

### 3.1 PCB 布局 vs 芯片（IC）布局的差别

这一点非常关键，直接决定了不能照搬 Google Nature 2021 那套芯片布局方案。

| 维度 | IC 布局（Floorplan） | PCB 布局 |
|---|---|---|
| 对象数量 | 数百万标准单元 + 数百宏单元 | 通常 100 ~ 5000 个器件 |
| 尺寸差异 | 标准单元高度统一 | **0201 电阻到大型 BGA，面积差 10000 倍** |
| 摆放面 | 单面 | **双面（Top / Bottom）** |
| 旋转 | 有限 | 4 种正交角度（有时任意角） |
| 硬约束来源 | 主要是设计本身 | **大量来自机械结构（外壳、接口、螺丝孔、限高）** |
| 目标函数 | 线长、时序、拥塞 | 线长、拥塞、**热、EMC、可制造性、可维修性** |
| "对错"判定 | 相对客观 | **大量依赖工程师经验，主观性强** |
| 数据量 | 公开 benchmark 丰富 | **几乎没有公开数据集，只能靠自有历史板** |

结论：PCB 布局是一个**强约束、小样本、多目标、含主观偏好**的问题。因此路线必须是"**先模仿人类，再优化目标**"，而不是"从零 RL 探索"。

### 3.2 布局质量的常用量化指标

- **HPWL（Half-Perimeter Wire Length，半周长线长）**：每个 Net 所有引脚的包围盒周长的一半之和。最经典、最快的线长估计。
- **Congestion（拥塞度）**：把板面切成网格，估计每格需要通过的走线数 vs 可容纳数。
- **Overlap（重叠面积）**：非法性度量，必须为 0。
- **Routability（可布通率）**：跑一次快速全局布线看能不能通。
- **Constraint Violation Count（约束违反数）**：去耦电容距离、限高、禁布区、极性等。
- **Thermal Hotspot（热点）**：功率密度分布的峰值。
- **Symmetry / Alignment（对称性 / 对齐度）**：人类工程师极其在意的"美观性"，实际关系到可制造性和可维修性。

## 四、如何给"设计规范"分类（知识工程的第一步）

设计规范文档拿到手后，**第一件事不是灌进向量库，而是分类**。建议分成三层：

### L1 — 硬规则（Hard Rule，可形式化、可自动判定）
特征：有明确的数值阈值和判定对象。
示例："BGA 下方去耦电容距电源引脚 ≤ 5mm"、"限高区内器件高度 ≤ 3.5mm"、"0402 电容间距 ≥ 0.5mm"。
处置：**转成规则引擎 DSL，写成可执行检查器**。同时也是布局 RL 的**动作掩码**和**惩罚项**。

### L2 — 软规则（Soft Rule，有倾向但需要判断）
特征：有方向性但阈值模糊，或需要综合权衡。
示例："高速信号尽量短"、"电源模块与模拟电路尽量远离"、"发热器件尽量分散"。
处置：**转成布局评分函数中的一项（带权重）**，权重由历史设计反推（逆强化学习思路）或由专家标定。

### L3 — 知识型（Knowledge，解释性内容）
特征：原理说明、案例、经验总结、失效分析。
示例："为什么参考平面不能跨分割"、"某项目 EMI 超标的整改过程"。
处置：**进 RAG 知识库，用于问答**。

> 这个 L1/L2/L3 分类是整个项目的**枢纽设计**：它同时定义了知识库的入库策略、规则引擎的规则来源、以及 RL 奖励函数的构成。请在项目一开始就和资深 PCB 工程师一起把它敲定。

## 五、给算法侧的"业务体感"建议

1. **一定要去看工程师实际布局的过程**（录屏或旁听 2~3 次完整布局）。你会发现他们的顺序是：先放固定件（连接器、按键、安装孔）→ 放大芯片（主控、DDR、电源模块）→ 划分区（Room）→ 放外围小件 → 反复微调。**这个顺序本身就是 RL 的动作序列先验。**
2. **理解"为什么这里不能动"**。很多位置是结构、认证（安规爬电距离）、供应链决定的，不是电气最优。模型必须学会把这些当作硬约束而不是可优化项。
3. **别低估"复用"**。工程师做新板时大量复用旧板的模块布局（DDR 组、电源模块）。**基于图相似度的"布局复用检索"往往比 RL 更快见效，且工程师接受度极高。**建议作为辅助布局的第一个可交付能力。
4. **DRC 干净 ≠ 设计好**。评价必须引入工程师主观打分。

## 六、推荐延伸阅读

**PCB 业务侧**
- Henry Ott, *Electromagnetic Compatibility Engineering*（EMC 圣经）
- Eric Bogatin, *Signal and Power Integrity – Simplified*（SI/PI 入门首选）
- IPC-2221 / IPC-7351 / IPC-2581 标准
- Cadence Allegro SKILL 官方参考手册、Allegro Extracta 用户指南

**算法侧**
- Mirhoseini et al., *A graph placement methodology for fast chip design*, Nature 2021（GNN + PPO 做芯片布局的奠基工作）
- Lai et al., *MaskPlace* (NeurIPS 2022)（视觉化布局表示 + 动作掩码）
- Lai et al., *ChiPFormer* (ICML 2023)（离线 RL + Decision Transformer，**最贴合我们"有历史数据、无仿真环境"的处境**）
- Cheng & Yan, *DREAMPlace / On Joint Learning for Solving Placement and Routing*（GPU 加速解析式布局）
- Cheng et al., *The Policy-gradient Placement and Generative Routing Neural Networks*
- Hu & Marek-Sadowska, 力导向 / 解析式布局经典方法（做 refinement 阶段用）
