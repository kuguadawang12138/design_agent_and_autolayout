## 一、问题定义

### 1.1 范围

给定一块板上**已完成主要器件布局**（主控、DDR、电源模块、连接器等大器件位置已定），自动决定**外围小器件**的位置：

| 类别 | 典型器件 | 数量级（单板） | 规则性 |
|---|---|---|---|
| **去耦/旁路电容** | 0.1uF、1uF、10nF 等 | 100 ~ 1000+ | 极强 |
| 上下拉电阻 | 1k ~ 100k | 50 ~ 300 | 强 |
| 串联匹配电阻 | 22R、33R、49.9R | 20 ~ 200 | 强 |
| 滤波器件 | 磁珠、小电感、TVS | 20 ~ 100 | 中 |
| ESD / 保护器件 | ESD 二极管 | 10 ~ 50 | 强 |
| 分压/上拉网络 | 电阻网络 | 10 ~ 100 | 中 |

**第一阶段只做去耦电容**（数量最多、规则最明确、物理目标最清晰），跑通后再扩展到其他类别。

### 1.2 形式化

给定一个"摆放任务" $T = (M, \mathcal{C}, E, R)$：
- $M$：主器件（BGA / QFP 等），已固定位置，含引脚阵列与网络分配
- $\mathcal{C} = \{c_1, ..., c_k\}$：待摆放的小器件集合，每个 $c_i$ 有封装尺寸、容值、两端所连网络 $(net_{pwr}, net_{gnd})$
- $E$：环境（板框、叠层、已摆放器件占位、禁布区、限高区、其他芯片、已有过孔与走线通道）
- $R$：适用的设计规则集（来自规则引擎）

求：$\{(x_i, y_i, \theta_i, s_i)\}_{i=1}^k$，使得目标函数最优且满足全部硬约束。

### 1.3 真正的物理目标（这一节请认真读）

很多人以为去耦电容的目标是"离芯片近"，这只是表象。**真正的目标是最小化电源分配网络（PDN）的环路电感**，因为去耦电容的有效频率上限由安装电感决定：

$$f_{\text{有效上限}} \approx \frac{1}{2\pi\sqrt{L_{\text{loop}} \cdot C}}$$

其中环路电感 $L_{\text{loop}}$ 由三部分构成：

$$L_{\text{loop}} = L_{\text{cap,ESL}} + L_{\text{trace}} + L_{\text{via}}$$

- $L_{\text{cap,ESL}}$：电容自身等效串联电感，由封装决定（0402 < 0603 < 0805），**器件选型决定，布局管不着**
- $L_{\text{trace}}$：焊盘到过孔的走线电感，**与走线长度成正比 → 布局能影响**
- $L_{\text{via}}$：过孔电感，与**过孔长度（到电源/地平面的层深）**和**电源过孔与地过孔的间距**相关，**布局能影响**

**因此正确的优化目标是**：
1. 电容焊盘到其电源/地过孔的走线尽可能短（过孔尽量贴着焊盘）
2. 电源过孔与地过孔尽可能靠近（回路面积小），这是**比"离芯片近"更重要的因素**
3. 电容到芯片电源引脚的路径尽可能短（但在有完整平面的情况下，这项的重要性低于前两项）
4. 电容在芯片周围/背面**分布均匀**，覆盖各个电源引脚区域
5. 不同容值的电容按频段搭配分布（大容值靠外，小容值靠内）

> **这就是为什么这个问题值得用 RL 而不是简单的"找最近空位"**：它是一个多目标、器件间相互影响（抢占空间和过孔资源）的组合优化问题。把这套物理目标准确地编码进奖励函数，是本方案成败的关键，**必须和 SI/PI 仿真工程师一起定**。

### 1.4 相关的工程概念（需要在建模时处理）

- **Fanout（扇出）**：BGA 引脚打过孔引出的模式。电容通常放在 BGA 背面，直接借用 fanout 过孔。
- **Via-in-pad（盘中孔）**：过孔直接打在焊盘上，电感最小，但成本高。板类不同策略不同。
- **共享过孔**：多个电容共用地过孔，节省空间但增加电感耦合。
- **Anti-pad（反焊盘）**：过孔穿过平面层时的开孔，过孔太密会把平面层"打成筛子"，破坏回流路径——**这是一个隐含的密度上限约束**。
- **背面摆放**：BGA 下方背面区域是黄金位置，但空间有限，需要竞争分配。

## 二、为什么这个问题适合 GNN + RL

### 2.1 诚实的技术论证

必须先承认：**单个电容的位置预测，用监督学习就能做**（给定芯片和引脚，回归一个坐标）。RL 的价值必须被证明，不能想当然。

RL 真正带来价值的地方在于：

| 特性 | 说明 | 监督学习为什么不够 |
|---|---|---|
| **器件间相互影响** | 电容 A 占了最优位置，电容 B 就只能退而求其次 | 监督学习独立预测每个电容，会预测出一堆重叠的位置 |
| **资源竞争与分配** | BGA 背面的黄金区域有限，谁该占，谁该让 | 需要全局协调，是组合优化问题 |
| **全局目标** | 覆盖均匀性、频段搭配、总体 PDN 效果，是整组电容的联合属性 | 监督学习优化的是逐点误差，不是全局质量 |
| **顺序依赖** | 先放大容值还是小容值，先占背面还是先占正面 | 天然的序列决策结构 |
| **可以超越人类** | 人类工程师在时间压力下摆的位置未必最优 | 监督学习的上限就是人类水平 |

> **必须做的对照实验**：先实现监督学习 / 行为克隆的 baseline，RL 版本必须在指标上显著优于它，否则老老实实用简单方案。**这个对照实验要写进第一版实验计划，不能省。**

### 2.2 GNN 在这里的作用

- 电容与主芯片是通过**网络（Net）**关联的，谁服务谁不是几何关系而是电气连接关系 → 天然的图结构
- 主芯片的引脚阵列、电源域划分、引脚的功能分组，都是图上的模式
- GNN 能泛化到**未见过的芯片封装**（不同 BGA 尺寸、不同引脚数），而 CNN 或固定输入的 MLP 不行
- 电容之间通过"共享电源网络"、"共享过孔"、"空间邻近"形成关系图，GNN 能建模它们的相互影响

## 三、数据构造

### 3.1 样本提取

```
从每块历史板中提取"摆放任务"样本：
  for 每个主芯片 M（引脚数 > 阈值，如 100）:
      找出所有服务于 M 的去耦电容（通过网络连接 + 距离启发式判定）
      记录：M 的封装与引脚阵列、电容集合及其容值/封装、
            电容的真实位置（人类答案）、环境（周边已摆器件、板框、层叠）
      → 一个样本
```

**样本量估算**：假设可用板 1 万块，每块板平均 5 个主芯片 → **5 万个摆放任务样本**，每个任务含 20~200 个电容 → **数百万条 (状态, 动作) 对**。对 BC 来说非常充裕。

### 3.2 "谁服务谁"的判定（关键预处理）

一个电容服务于哪个芯片的哪个电源引脚，网表里没有直接写，需要推断：

```
判定逻辑（规则 + 学习）：
  1. 电容两端网络：一端为 GND 网络，另一端为电源网络 net_p
  2. 找出所有连接 net_p 的芯片电源引脚
  3. 若只有一个芯片 → 直接归属
  4. 若多个芯片共用 net_p → 按历史布局中的物理距离归属（最近的芯片）
  5. 具体服务哪个引脚：最近邻匹配 + 匈牙利算法做全局最优匹配
```

**这一步的准确性直接决定训练数据质量，需要抽样人工校验（至少 200 个样本）。**

### 3.3 环境渲染

把环境栅格化为多通道 2D 图（以主芯片为中心，局部窗口，如 60mm × 60mm，网格 0.1mm → 600×600，可下采样到 256×256）：

| 通道 | 内容 |
|---|---|
| 0 | Top 面已占用（其他器件） |
| 1 | Bottom 面已占用 |
| 2 | 主芯片焊盘/引脚位置 |
| 3 | 目标电源网络的引脚位置（热图） |
| 4 | 地引脚位置 |
| 5 | 已有过孔位置（fanout 过孔） |
| 6 | 禁布区 |
| 7 | 限高约束图 |
| 8 | 板框内外 |
| 9 | 当前已摆放的本组电容 |
| 10 | 过孔密度图（Anti-pad 密度，反映平面完整性） |

### 3.4 数据增强

- 镜像 / 90° 旋转（整个局部场景一起变换）
- 芯片型号脱敏后的跨板迁移（同一封装类型的不同芯片视为同类）
- 随机遮蔽部分环境信息（提升鲁棒性）
- 电容顺序打乱（生成多条专家轨迹）

## 四、MDP 建模

### 4.1 状态

**双分支表示**（图 + 网格，见 `04-算法方案` 第 6.2 节的论证）：

```
图分支（GNN）：
  节点：主芯片、主芯片的引脚（电源/地引脚）、待摆放电容、已摆放电容、相关网络
  边：芯片-引脚、引脚-网络、网络-电容、电容-电容（同网络/空间邻近）
  → 输出：当前待摆放电容的嵌入 h_c、上下文嵌入 h_ctx

网格分支（CNN）：
  上述 11 通道局部环境图（256×256）
  → 输出：空间特征图 F ∈ R^{256×256×d}

融合：用 h_c 通过 FiLM 调制 F，得到"针对当前这个电容的空间适宜度特征"
```

### 4.2 动作空间（关键工程设计）

**不要直接用 256×256×8 的全网格动作空间**，太大且大部分位置无意义。改用**候选位置生成 + 排序**：

```
候选生成器（几何 + 规则，非学习）：
  1. 在主芯片背面对应区域，按 fanout 过孔间隙生成候选位（通常是规则阵列）
  2. 在主芯片四周环形区域按网格生成候选位
  3. 每个候选位 × 2 种旋转（0°/90°）× 2 个面
  4. 用规则引擎过滤掉非法候选（重叠、禁布、间距违规、面限制）
  → 输出 N 个合法候选（典型 N = 200 ~ 2000）

动作 = 从 N 个候选中选 1 个
策略网络 = 对每个候选打分 → softmax → 采样
```

**这个设计的好处**：
- 动作空间小 1~2 个数量级，训练快得多
- **硬约束由候选生成器保证，模型物理上无法输出非法动作**
- 候选的特征可以直接从网格特征图上按坐标采样（`grid_sample`），复用 CNN 特征
- 候选数量可变，用注意力/指针网络处理，天然支持不同规模

**NeurPCB 工程参考（2026-08-07 合并，详见 `docs/10` §2.3.D ~ §2.3.D.1）**：

NeurPCB（[github.com/pretend1111/NeurPCB](https://github.com/pretend1111/NeurPCB)，本仓库 `NeurPCB/`）实机审计结论：**不是 GNN+RL**，而是 LLM Agent + KiCad 工程集成。但其 **确定性 Skills 与本文候选生成器同构**，可直接作 B2 启发式基线与 M2 候选生成器的实现参考：


> Louvain 模块划分 baseline 见 `04` §2.1，此处不重复。

### 4.3 决策顺序

按启发式固定顺序（降低学习难度）：
```
1. 按容值从小到大（小容值电容对距离最敏感，优先占最好位置）
2. 同容值内，按所服务的电源引脚重要性排序（核心电源 > IO 电源）
3. 同优先级内，按引脚在芯片上的位置顺序（避免随机性）
```
后续可尝试让模型学习顺序（Pointer Network），但**PoC 阶段用固定顺序**。

### 4.4 奖励函数

**每步稠密奖励**：

$$r_t = -\left[ w_1 \hat{L}_{\text{loop}}(a_t) + w_2 d_{\text{pin}}(a_t) + w_3 \text{ViaPenalty}(a_t) + w_4 \text{BlockPenalty}(a_t) \right]$$

- $\hat{L}_{\text{loop}}$：估计环路电感（用解析近似公式，见 1.3 节；需与 SI 工程师确认公式与系数）
- $d_{\text{pin}}$：到目标电源引脚的曼哈顿距离（归一化）
- $\text{ViaPenalty}$：新增过孔数、过孔密度超限惩罚（保护平面完整性）
- $\text{BlockPenalty}$：是否阻挡了走线通道 / 占用了高价值区域

**终局奖励**：

$$r_T \mathrel{+}= -\left[ v_1 \text{CoverageUniformity} + v_2 \text{FreqBandBalance} + v_3 \text{RuleViolations} \right] + v_4 \cdot \text{Critic}_{\text{expert}}$$

- $\text{CoverageUniformity}$：电容围绕芯片分布的均匀性（用角度直方图熵或最近邻距离方差衡量）
- $\text{FreqBandBalance}$：不同容值的空间分布是否符合"小容值靠内、大容值靠外"
- $\text{RuleViolations}$：软规则违反数
- $\text{Critic}_{\text{expert}}$：从工程师 pairwise 偏好学到的判别器打分

**规则 Critic 层（Critic_rule，2026-08-07 合并自 NeurPCB `routing/critic.py`）**：

与 $\text{Critic}_{\text{expert}}$（偏好判别器，需 pairwise 标注）**是不同层**，可先做、后做：

| 层级 | 来源 | 检查项 | 对接奖励 / 评估 |
|---|---|---|---|
| **Critic_rule**（NeurPCB `fast_check`） | 纯几何规则，毫秒级 | 模块/器件重叠、板框越界、最小间距 | 每步/终局 **硬约束惩罚**；`RuleViolations` 的可解释分解；与候选生成器动作掩码双重保障 |
| **Critic_expert**（本文原有） | Bradley-Terry 偏好学习 | 工程师主观偏好 | 终局奖励 $v_4 \cdot \text{Critic}_{\text{expert}}$ |

NeurPCB `fast_check` 已实现的具体 category（可直接映射为惩罚项）：

- `overlap` / `component_overlap` → 重叠面积惩罚（critical，一票否决）
- `board_edge` → 板框越界惩罚
- `spacing` → 器件间距不足惩罚

NeurPCB `router.py` 的飞线分析（总长度、交叉数、拥塞热力图、磁力场评分）可作为 $\text{BlockPenalty}$ / routability 的**辅助稠密信号**，首战可选。

**权重标定方法**（不要拍脑袋）：
1. 初值由 SI 工程师给出量级
2. 用逆强化学习思路：调整权重使得"人类布局的奖励"显著高于"随机扰动布局的奖励"
3. 用工程师 pairwise 标注做最终校准

### 4.5 与真实物理的校准（不可跳过）

选 20 个典型场景，让 **SI/PI 仿真工程师**对以下三组方案做真实 PDN 阻抗仿真：
- 人类布局
- 代理评估器认为最优的布局
- 随机合法布局

**验证代理评估器的排序与真实仿真结果的相关性（Spearman ρ 目标 > 0.8）**。若相关性差，说明奖励函数写错了，必须回炉——**在这之前不要开始大规模 RL 训练，否则是在优化一个错误的目标。**

> 真实仿真是校准代理指标最可靠的手段，有仿真条件就一定要用上。

| Louvain 模块划分 | 网图社区检测初稿 | `04` §2.1 | **已有，不重复** |

**不建议照搬**：LLM Tool-Calling 决策环（与 RL Policy 冲突；API 成本/延迟）；官网声称的 GNN+RL（代码不存在）。

## 五、网络结构

```
┌────────────── 图分支 ──────────────┐
│ 异构 GNN（HGT，4 层，d=128）        │
│  节点：Chip / Pin / Cap / Net       │
│  → h_cap_current（当前待摆电容）     │
│  → h_context（全局池化）            │
└─────────────────┬──────────────────┘
                  │
┌─────────────────▼──────────────────┐
│ 网格分支：轻量 U-Net（11ch→64ch）    │
│  ← FiLM 调制（用 h_cap_current）     │
│  → 空间特征图 F ∈ R^{256×256×64}    │
└─────────────────┬──────────────────┘
                  │
┌─────────────────▼──────────────────────────────┐
│ 候选打分头                                       │
│  对每个候选 (x,y,θ,s)：                          │
│    f_i = grid_sample(F, x, y)  ← 空间特征        │
│    g_i = MLP(候选的手工特征：到引脚距离、          │
│              估计电感、是否背面、周边占用率...)     │
│    score_i = MLP([f_i, g_i, h_cap, h_context])   │
│  → softmax(scores) → 策略分布                    │
└─────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────┐
│ 价值头：[h_context, GAP(F)] → MLP → V(s)         │
└─────────────────────────────────────────────────┘
```

**参数量控制在 10~30M**，单卡可训练，推理快。不要一上来就堆大模型。

## 六、训练流程

### 阶段 0：基线（第 1 个月内完成）

**必须先有基线，否则无法判断 RL 有没有价值。**

| 基线 | 说明 |
|---|---|
| B0 随机合法摆放 | 下限 |
| B1 贪心最近邻 | 每个电容选距离目标引脚最近的合法位置 |
| B2 规则驱动启发式 | 按现有设计规范写的启发式算法（**可参考 NeurPCB `skill_decap_cluster` 实现**，见 §4.2） |
| B3 监督学习 | GNN + CNN 直接回归/分类预测位置（无序列决策） |
| B4 行为克隆 | 序列决策 + 交叉熵模仿专家 |
| **RL** | 必须显著优于 B2 和 B4 才算成功 |

> **诚实提醒**：B2（规则启发式）可能出乎意料地强，因为这个问题本身规则性就很强。如果 RL 打不过 B2，那就说明这个场景不需要 RL——**这不是失败，这是有价值的结论**，可以及时把 RL 的火力转移到规则性更弱、更需要权衡的问题上（如模块分区、关键器件布局）。

### 阶段 1：行为克隆（第 2~3 个月）

```
损失：L_BC = CrossEntropy(π(a|s), a_expert)
     + 辅助损失：预测该位置的估计电感（多任务，加速收敛）
数据：数百万条 (状态, 专家动作)
评估：Top-1 / Top-5 候选命中率、与专家位置的距离中位数
```

**BC 的成功标准**：预测位置与专家位置距离中位数 < 2mm，Top-5 候选命中率 > 60%。

### 阶段 2：离线 RL（第 3~4 个月）

用带回报标注的历史轨迹训练 IQL / CQL：
- 回报来自代理评估器（已校准）
- 可以把"人类布局"和"人工扰动的次优布局"都放进离线数据集，形成回报梯度
- 优势：不需要在线交互，训练稳定

### 阶段 3：在线 PPO 微调（第 4~5 个月）

```
环境：自研 Gymnasium 环境，向量化并行（目标 ≥ 1000 步/秒）
初始化：BC / 离线 RL 权重
算法：PPO + GAE + 候选动作掩码
正则：KL(π ‖ π_BC) 惩罚，防止偏离人类风格太远
课程学习：从电容数少的简单场景（< 30 个）逐步到复杂场景（> 200 个）
```

### 阶段 4：偏好对齐（第 5 个月，与阶段 3 并行）

pairwise 偏好标注分散给多位设计工程师完成：
```
1. 生成 pairwise 布局方案对（模型 vs 人类、模型 vs 模型）
2. 内部标注平台：并排展示两个方案，工程师选更好的
   → 目标 5000 ~ 10000 对（多位工程师分散标注，每人 100~200 对）
3. Bradley-Terry 训练判别器
4. 判别器加入 RL 终局奖励，或用于候选方案排序
```

## 七、评估方案

### 7.1 测试集

从未参与训练的项目中选 100 个摆放任务（覆盖不同芯片类型、板层数、板类）。

### 7.2 指标

| 类别 | 指标 | 目标 |
|---|---|---|
| **合法性** | 硬约束违反数 | **= 0（一票否决）** |
| 物理 | 平均估计环路电感 vs 人类 | ≤ 1.0（不劣于人类） |
| 物理 | **真实 PDN 阻抗仿真（抽样 20 例）** | 目标频段阻抗不劣于人类布局 |
| 几何 | 到目标引脚距离中位数 vs 人类 | ≤ 1.1 |
| 几何 | 与人类位置的偏差中位数 | ≤ 3mm |
| 分布 | 覆盖均匀性指标 | ≥ 人类 |
| 规范 | 软规则违反数 | ≤ 人类 |
| 效率 | 单任务推理耗时（200 个电容） | < 30s |
| **主观** | **工程师盲评（模型 vs 人类，选更好的）** | **模型胜率 ≥ 40%（打平即成功）** |
| **业务** | **建议采纳率**（最终设计中位置偏差 < 2mm 的比例） | **≥ 50%** |
| **业务** | **工时节省**（实测对比） | **≥ 40%** |

### 7.3 消融实验（证明技术选择的必要性）

| 消融 | 验证什么 |
|---|---|
| 去掉 GNN 分支（仅 CNN） | GNN 是否必要 |
| 去掉 CNN 分支（仅 GNN） | 几何信息是否必要 |
| 去掉 RL（仅 BC） | **RL 是否带来增量价值（最重要的消融）** |
| 去掉环路电感项（仅用距离） | 物理建模是否有效 |
| 去掉偏好判别器 | 主观对齐是否有效 |
| 不同候选生成策略 | 动作空间设计的影响 |

## 八、月度里程碑（RL 主线任务书）

| 月 | 目标 | 交付物 | 关卡 |
|---|---|---|---|
| **M1** | 数据管道 + 问题定义 | `.brd` 提取 → 摆放任务样本；100 个样本人工校验；**基线 B0/B1/B2 实现** | 能否稳定提取样本？基线效果如何？ |
| **M2** | 图建模 + 环境 | 异构图构建、环境渲染、候选生成器、代理评估器 v1 | 评估器与 SI 仿真的相关性 > 0.7 |
| **M3** | 监督/BC 模型 | B3、B4 模型训练完成，与基线对比 | **BC 是否优于 B2？位置偏差中位数 < 2mm？** |
| **M4** | RL 环境 + 离线 RL | Gymnasium 环境（≥1000 步/秒）、IQL/CQL 实验 | 离线 RL 是否优于 BC？ |
| **M5** | PPO 微调 + 偏好对齐 | RL 模型、5000 对偏好标注、判别器 | **RL 是否显著优于 BC？** |
| **M6** | 集成与验证 | 端到端流水线、Allegro 写回、100 任务评测、盲评报告 | 采纳率 ≥ 50%？盲评胜率 ≥ 40%？ |

**每个月末必须有一次"是否继续"的评估**。如果 M3 时 BC 打不过规则启发式 B2，就要认真考虑：这个场景是否真的需要深度学习，还是应该把 RL 的火力转向更需要权衡的问题（模块分区、关键器件布局）。**及时转向不是失败，是负责任的工程决策。**

## 九、成功之后的扩展路径

```
去耦电容摆放（M1~M6）
   ↓ 同一套技术栈，换数据和奖励
其他外围小器件（上下拉、匹配电阻、滤波）    ← V1 上半年
   ↓ 扩大动作空间与决策粒度
功能模块内部布局（电源模块、时钟电路）        ← V1 下半年
   ↓ 引入模块间关系
整板功能分区（Room 划分）                    ← V2
   ↓
关键器件布局 → 全板布局辅助                  ← V2+
```

**每一步复用前一步的**：数据管道、图建模框架、环境渲染、候选生成、代理评估器、训练基础设施、偏好标注平台。这就是为什么从最小的问题开始不是"降低目标"，而是**在搭建一个可以不断向上生长的技术底座**。
